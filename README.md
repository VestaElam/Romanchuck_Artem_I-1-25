# Лабораторные работы по C++

Учебный репозиторий с первыми практическими заданиями, выполненными на первом курсе направления «Прикладная информатика».

## О репозитории

Здесь собраны первые консольные программы на C++, которые помогли познакомиться с синтаксисом языка, базовыми конструкциями и алгоритмическим мышлением.

## Технологии

- C++
- Консольные приложения
- Базовые алгоритмы

## Содержание

| Файл | Описание |
|---|---|
| `cpp-lab-02.cpp` | Вторая лабораторная работа |
| `cpp-lab-01.cpp` | Первая лабораторная работа |

## Запуск

Для сборки одной из работ с помощью GCC:

```bash
g++ cpp-lab-02.cpp -o lab2
./lab2
```

> Репозиторий создан в учебных целях и будет дополняться по мере обучения.
